# Muhammad Areeb Khan: Portfolio

Plain HTML, CSS and JavaScript. No build step.

## Run it
Double-click `index.html`, or serve the folder with any static server.

## Folder
```
index.html          page content
css/style.css       design tokens (top of file), layout, light and dark themes
js/main.js          menu, theme toggle, signal trace, active nav link
assets/areeb.jpg    portrait
assets/Muhammad_Areeb_Khan_CV.pdf   CV for the Download button
PROMPT.md           the prompt used to design this site
```

## Things to edit
- **Photo:** replace `assets/areeb.jpg` (keep the name, or update the `<img>` in `index.html`). A square photo works best.
- **Trainee Engineer role:** in `index.html`, find `EDIT:` in the Experience section and add one or two lines about your work at SGS.
- **Projects:** add or change `<article class="project">` blocks. Add links the same way as the featured project.
- **Colours:** change the variables at the top of `css/style.css`.

## Deploy
- **Vercel / Netlify:** drag the folder in, or connect a GitHub repo. No settings needed.
- **GitHub Pages:** push the folder to a repo, then enable Pages from the main branch.
